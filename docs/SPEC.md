# AGELIKE — Architecture & Contract Specification

A browser-based 4X fantasy strategy game in the spirit of Age of Wonders 4 (base game + expansions),
built with **vanilla JavaScript, Canvas 2D and DOM**, with **no external dependencies, no external
images, no external audio files**. Everything visual is drawn procedurally in code; all music is
public-domain classical repertoire transcribed to note data and played by our own Web Audio synth.

Read this whole document before writing code. Every module must follow the contracts here.
If a contract is missing something you need, add a *small, additive* helper in your own file and
document it at the top of that file — never change another module's signature.

---

## 0. Ground rules

* Plain scripts, **no ES modules, no `import`/`export`, no bundler-only syntax**. Every file is an
  IIFE that attaches to the global namespace `AOW` (`window.AOW`). Reason: the game must run from a
  single self-contained `dist/index.html` opened via `file://` and as a claude.ai artifact.
* File header pattern:
  ```js
  // src/game/rules.js — economy, research and action rules
  (function (AOW) {
    'use strict';
    const Rules = {};
    // ...
    AOW.Rules = Rules;
  })(window.AOW = window.AOW || {});
  ```
* Script order is fixed by `index.html`. Load order: core → art → data → game → render → audio → ui → main.
  You may reference other namespaces lazily inside functions (they are all present at runtime), but
  never at file top-level unless the file is loaded earlier in the order.
* No `console.log` spam. Use `AOW.log(...)` (wraps console with a debug flag).
* Deterministic randomness: all gameplay randomness goes through `AOW.RNG` instances seeded from the
  game seed. Rendering/VFX may use `Math.random`.
* Performance targets: world map 60 fps at 1080p with 2,500 hexes; sprite generation on first use is
  cached; nothing allocates per frame in hot loops needlessly.
* Language: UI is bilingual **Korean (default) + English**. Every user-facing string goes through
  `AOW.I18n`. Content names/descriptions are `{ko:'…', en:'…'}` objects, resolved with `AOW.L(obj)`.
* Code quality: small functions, clear names, JSDoc for public APIs. No frameworks.

## 2. Core APIs (already implemented — use them)

### AOW.RNG
```js
const rng = new AOW.RNG(seed);   // seed: integer or string
rng.next()          // float [0,1)
rng.int(min, max)   // inclusive ints
rng.pick(array)     // element
rng.chance(p)       // boolean
rng.shuffle(arr)    // in place, returns arr
rng.fork(label)     // new RNG derived deterministically
```
### AOW.Noise
`AOW.Noise.simplex2(x, y, seed)` in [-1,1]; `AOW.Noise.fbm2(x, y, seed, octaves=4, lacunarity=2, gain=0.5)`.
### AOW.M
`clamp, lerp, smoothstep, mod, dist, angle, easeInOut, hashInt(i), hash2(x,y)`.
### AOW.Color
`hsl(h,s,l,a)`, `parse('#rrggbb'|'rgb(a)')→[r,g,b,a]`, `toCss([r,g,b,a])`, `mix(c1,c2,t)`, `shade(css, amt)` (amt −1..1),
`saturate(css, amt)`, `alpha(css, a)`.
### AOW.Hex (pointy-top hexes, "odd-r" offset storage)
```
Hex.SIZE = 36                    // outer radius in world px at zoom 1
Hex.W = sqrt(3)*SIZE, Hex.H = 2*SIZE, Hex.ROW_H = 1.5*SIZE
Hex.toPixel(col,row) → {x,y} center in world px
Hex.fromPixel(x,y) → {col,row}
Hex.corners(cx,cy, size=SIZE) → [{x,y}×6] starting at top (angle -90°), clockwise
Hex.idx(col,row,W) / Hex.inBounds(col,row,W,H)
Hex.neighbors(col,row) → [{col,row}×6] in direction order DIRS: 0=E,1=SE,2=SW,3=W,4=NW,5=NE  (clockwise from east)
Hex.neighbor(col,row,dir)
Hex.dist(c1,r1,c2,r2)
Hex.ring(col,row,radius) / Hex.spiral(col,row,radius)  (list of {col,row}, unbounded — filter with inBounds)
Hex.line(c1,r1,c2,r2) → list of hexes
Hex.toCube(col,row) → {x,y,z} ; Hex.fromCube(x,y,z)
Hex.astar(startIdx, goalIdx, W, H, costFn(fromIdx,toIdx)→number|Infinity, opts) → {path:[idx…] (excluding start), cost} | null
Hex.reachable(startIdx, W, H, budget, costFn) → Map(idx → cost)
```
Edges: direction `d` of hex A leads to neighbor B; the shared edge between A's corner `d` and corner `d+1` ... concretely the edge toward direction d is between corners `(d+1)%6` and `(d+2)%6` of `Hex.corners` (top corner = index 0, corners clockwise). `Hex.edgeCorners(cx,cy,d,size)` returns the two corner points for direction d.

### AOW.Events
`Events.on(name, fn) → off()`, `Events.off(name, fn)`, `Events.emit(name, payload)`, `Events.once(name, fn)`.
Emit synchronously. Canonical event names are listed in §9.

### AOW.I18n
`I18n.add({ko:{key:'…'}, en:{key:'…'}})` (each module adds its own keys; keys namespaced like `ui.endTurn`, `city.build`).
`AOW.t(key, params)` → string with `{name}` substitution; falls back to en, then the key.
`AOW.L(obj)` → `obj[lang] || obj.en || obj.ko || String(obj)`.
`I18n.lang` ('ko'|'en'), `I18n.setLang(lang)` emits `i18n:changed`.

### AOW.Data
`Data.define(kind, obj)` registers `obj` under `Data[kind][obj.id]` (kinds: forms, cultures, traits, buildings,
improvements, abilities, statuses, units, tomes, spells, heroSkills, heroClasses, items, wonders, names, empireSkills, rulerTypes, terrains, features).
`Data.list(kind)` → array; `Data.get(kind,id)` throws if missing (use `Data.has`).
`Data.validate()` runs cross-reference checks and returns an array of error strings (main.js calls it in dev).

### AOW.Art
```
Art.sprite(key, w, h, drawFn(ctx, w, h, params), opts)   // register a generator; opts.anchor {x:0..1,y:0..1} default {0.5,1}
Art.get(key, params) → HTMLCanvasElement (cached per key+JSON(params))
Art.draw(ctx, key, x, y, params, {scale=1, alpha=1, flip=false, rotation=0})  // draws with anchor at (x,y)
Art.canvas(w,h) → {cv, ctx}  (offscreen)
Art.hexPath(ctx, cx, cy, size)    // traces pointy-top hexagon path (no fill)
Art.rrect(ctx,x,y,w,h,r)          // rounded rect path
Art.grad(ctx, x0,y0,x1,y1, stops)  // linear gradient from [[t,color],…]
Art.rgrad(ctx, x,y,r0,r1, stops)   // radial
Art.noiseFill(ctx, x,y,w,h, {seed, scale, colors:[c1,c2], alpha})  // cheap cached noise texture overlay
Art.shadow(ctx, x,y,w,h, alpha)    // soft elliptical ground shadow
Art.outline(ctx, path fn, color, width)
Art.text(ctx, str, x, y, {font,size,color,align,stroke,shadow})
Art.hash(str) → int
```
Art style rules (see §7).

### 3.0.1 Spell `effect` vocabulary (the engine implements these generically; unknown `special` ids are ignored gracefully)
Combat spells (kind 'combat', target 'enemy_unit'|'ally_unit'|'unit'|'hex'|'all_enemies'|'all_allies'): `{type:'damage', channel, amount, area:0|1|2, status:{id, chance:0..100, duration}}`, `{type:'heal', amount, cleanse:true}`, `{type:'status', status, duration, chance, area}`, `{type:'summon', unit, count}`, `{type:'teleport', range}`, `{type:'resurrect', hpPct}`, `{type:'dispel'}`, `{type:'push', distance}`, `{type:'special', id}`. Combat spells cost `{mana, cp}` where cp is combat casting points (a side has `combatCasting.cpMax` per battle round; default 10 per battle, +5/round).
World spells: kind 'unit_enchant' `{enchant:{appliesTo:[tags|'all'|'racial'], effects:{...§3.1}, attackChannel:'fire', attackStatus:{id,chance}}}`, kind 'city_enchant' `{enchant:{effects:{...}}}` target 'city', kind 'summon' `{effect:{type:'summon', unit, count}}` target 'city' (arrives next to a city) or 'hex' (in domain), kind 'transform' `{effect:{type:'terraform', terrain, feature, radius}}` target 'province', kind 'strategic' target 'army'|'city'|'province'|'player'|'empire' with effect `{type:'heal'|'status'|'resource'|'reveal'|'stability'|'damage'|'special', ...}`, kind 'empire' (permanent passive) `{effects:{...§3.1}}`. Mana upkeep for enchantments in `upkeep.mana`.

### 3.1 `effects` vocabulary (used by traits, buildings, tome passives, empire skills, enchantments, items, hero skills)

`food, production, gold, mana, knowledge, draft, imperium, stability, growthPct, foodPct, productionPct, goldPct, manaPct, knowledgePct,

## 4. Game state (src/game/state.js)

```js
Game = {
  version:1, seed, turn:1, W, H, settings:{ mapSize, players, difficulty, victory:{...}, realmTraits:[…] },
  // Hex layers (typed arrays of length W*H)
  terrain:Uint8Array,   // index into State.TERRAINS = ['ocean','coast','lake','grass','forest','hills','mountain','desert','snow','swamp','volcanic']
  feature:Uint8Array,   // State.FEATURES = ['none','forest','dense_forest','hills','mountain','peak','ruins','crystal','ash','oasis','ice','mushroom','ancient_tree']
  height:Float32Array,  // 0..1 continuous elevation for shading
  river:Uint8Array,     // 6-bit mask of edges (dir bits) carrying a river
  road:Uint8Array,      // 6-bit mask of edges with road
  province:Int16Array,  // province id (-1 for water)
  owner:Int8Array,      // player id owning the hex (domain) or -1
  structure:Int16Array, // index into game.structures or -1 (city, outpost, wonder, node, free city, infestation)
  explored:Uint8Array[] // per player: 0/1 per hex
  visible:Uint8Array[]  // per player, recomputed
  provinces:[{ id, hexes:[idx], center:idx, terrain:tid, feature:fid, resource:null|'gold'|'mana'|'food'|'production'|'knowledge'|'draft', magicMaterial:null|'…',
               owner:-1, cityId:-1, improvement:null|improvementId, annexTurn }],
  structures:[{ id, kind:'city'|'outpost'|'wonder'|'node'|'free_city'|'infestation'|'teleporter', hex, owner, refId (cityId / wonderId etc), cleared:bool, guardArmyId }],
  cities:[{ id, name, owner, hex, tier:0..5 (0=outpost), pop:1, growth:0, provinces:[pid], buildings:[id], queue:[{type:'unit'|'building'|'improvement', id, progress, pid?}],
```

## 5. Rules engine contract (src/game/rules.js, turn.js)

Combat (src/game/combat.js):
```
Combat.create(game, {attackerArmyIds, defenderArmyIds, hexIdx, siege:false}) → battle
battle = { id, W:20, H:12, hexes:{terrain, obstacle}, units:[{ id, gameUnitId, side:0|1, col,row, hp, maxHp, ap:3, mp, facing, statuses, hasRetaliation, hasActed, hero, stats }],
           side:0, round:1, log:[], winner:null, cp:{0:n,1:n}, spellsCast:{}, walls?:[...], gate?:… }

```
Combat rules to implement: 3 AP per unit (move costs AP by distance/MP; attack costs remaining AP), melee retaliation once per round, flanking (attack from side ±2 dirs of facing: −2 def; from rear: def ignored), defense mode (+3 def/res until next turn), first strike, charge (+dmg after moving ≥3 hexes), pike brace (retaliate first vs charging cavalry; +dmg vs cavalry), ranged accuracy falls with range & obstruction, repeating attacks (multiple weaker hits), critical (10% +50%), fumble (5% half), morale states (breaking/fleeing at ≤ −5), status effects with resistance rolls, healing/support abilities, heroes with 3 AP and abilities, combat spells per side limited by combat CP, ZOC (moving out of enemy adjacency costs all AP), obstacles (rocks/trees block), siege walls/gates with HP if attacking a walled city, retreat after round 3, auto-resolve via simplified simulation with the same stat model.

Diplomacy: `Diplomacy.propose(game, from, to, kind, terms)`, `Diplomacy.aiRespond`, `Diplomacy.declareWar`, `Diplomacy.opinion(game, a, b)`, `Diplomacy.tick(game)`.
AI: `AI.playTurn(game, pid)` — city management, research, spells, army movement, expansion, wonder clearing, war decisions; must be time-bounded (< 200 ms per AI on medium map).

## 7. Art direction (mandatory for all art files)

* **Style**: painterly stylized high fantasy (NOT pixel art, NOT flat icons). Smooth gradients, soft
  shading, subtle dark outlines (rgba(20,15,30,0.5)), rim light from top-left, ambient occlusion at
  ground contact, saturated but not neon colors. Think a hand-painted board game map.
* **Light**: key light from top-left (−45°), warm; shadows cool (bluish) to the bottom-right.
* **Scale** (world map, zoom 1): hex outer radius 36 px; a unit sprite is ~34 px tall (large 44, huge 56);
  a tier-3 city occupies ~1.8 hexes visually; trees ~10–16 px.
* **Palette**: use `AOW.Palette` (biomes, affinities, cultures, UI). Affinity colors: order gold `#e8c357`
  / white, chaos red-orange `#e0452b`, nature green `#5fb043`, materium amber-brown `#c07a2a`, astral
  blue-violet `#5a7ff0`, shadow purple-black `#7b3fa0`.
* **UI look**: deep charcoal/navy panels `#151a26` → `#1e2536`, gold filigree borders `#c9a24a`,
  parchment tooltips `#efe3c6` with dark ink `#2b2116`, serif display font (Cinzel-like feel; use
  `"Cinzel", "Noto Serif KR", Georgia, serif` stack with system fallback), Korean text uses
  `"Noto Serif KR", "Nanum Myeongjo", serif` for titles and `"Noto Sans KR", system-ui` for body.
* **Consistency**: every sprite generator must accept a `seed` and produce deterministic output;
  animations use `frame` param (0..3 for idle/walk, 0..5 for attack).
* **Verification**: each art module must include a `AOW.<Module>.demo(canvas)` function that draws a
  gallery of everything it can draw (used by `demo.html` and screenshots). Art agents must run
  `node tools/shot.js demo.html?module=<name> out.png` and inspect the PNG to iterate until the
  result looks genuinely good (no boxes, no stick figures; real silhouettes, shading, details).
